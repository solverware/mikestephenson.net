# Reference PDF audit checklist

## Artifact
- [ ] Source URL and retrieval date
- [ ] Page count, dimensions, orientation
- [ ] PDF metadata and SHA-256 hash

## Geometry
- [ ] Page bounds and margins
- [ ] Content bounds
- [ ] Main/sidebar widths and gutter
- [ ] Header height and alignment
- [ ] Section start positions
- [ ] Baseline and line-spacing estimates

## Typography
- [ ] Embedded font names/types
- [ ] Font sizes by semantic role
- [ ] Weight and italic usage
- [ ] Text colors by role
- [ ] Line height and tracking
- [ ] Bullet glyph and hanging indent
- [ ] Dates and metadata treatment

## Color and hierarchy
- [ ] Background, primary text, muted text, accent, rules
- [ ] Name / descriptor / contact hierarchy
- [ ] Primary narrative column vs secondary information rail
- [ ] Section order and grouping
- [ ] Links and link styling

## Adaptation for Mike
- [ ] Principles to retain
- [ ] Choices to change for an editorial personal site
- [ ] Desktop and mobile layout
- [ ] PDF-specific vs web-specific choices
- [ ] Accessibility and selectable text
